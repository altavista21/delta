# Delta Workspace

Ruang kerja berbasis profesi untuk sembilan jenis pengguna, mengikuti PRD Role-Based AI Workspace System.

## Status implementasi

- Dashboard responsif dengan navigasi profesi.
- Sembilan dashboard profesi sesuai PRD.
- Perpindahan profesi dan filter modul di sisi antarmuka.
- Kartu ringkasan dan panel asisten AI sebagai antarmuka awal.

## Menjalankan lokal

```bash
npm install
npm run dev
```

## Catatan penting

Ini merupakan fondasi UI/MVP. Login dan registrasi, penyimpanan data, kontrol akses RBAC di sisi server, integrasi AI, sinkronisasi real-time, serta validasi laporan belum diimplementasikan. Angka ringkasan saat ini adalah data contoh dan bukan data bisnis nyata. Jangan gunakan untuk keputusan keuangan, pajak, investasi, atau keputusan profesional sebelum backend, otorisasi, sumber data, dan validasi domain selesai.
